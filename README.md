# OpenEmux evidence

Screenshots and design assets referenced from [OpenEmux](https://github.com/guilhermefeitosa66/OpenEmux) issues.

- `qa/issue-<N>/<run>/` — QA screenshots for issue N, one folder per test run.
- `design/issue-<N>/` — design specs and assets produced while planning issue N.

Nothing here is built or shipped; it only exists so issue comments can embed images.
