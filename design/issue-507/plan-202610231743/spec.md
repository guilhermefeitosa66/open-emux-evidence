# Bezels for 4:3 games — UI spec (issue #507)

## Where
Preferences → **Video** page, a new `Adw.PreferencesGroup` placed **between "In-Game Bar" and "Shaders"**.

- Title: `Bezels`
- Description: `Decorate the black bars beside 4:3 games on a wide screen. Applies to the next game you start`
- Footer note (a dim `Gtk.Label`, `dim-label` + `caption`, below the group's rows, or the group's
  description second sentence if a footer is awkward): `Only consoles whose games are 4:3 are listed. Handhelds fill their own shape and get no bezel.`

## Rows
One `Adw.ComboRow` per console in `bezels.BEZEL_CONSOLES`, in `SYSTEM_IDS` order, built exactly like the
shader rows: title `"<ID> — <display name>"`, `console_icon(console_id)` as prefix.

Model (translated): `None` · `Simple` · `Custom image…`

- `None` — default for every console.
- `Simple` — the built-in OpenEmux frame (dark radial gradient, thin grey rim around the game).
- `Custom image…` — opens a `Gtk.FileDialog` (title `Choose a bezel image`, filter `PNG images`, `*.png`).
  - Accepted → the row's subtitle shows the file name (`psx-bezel.png`) and a flat icon button
    (`folder-open-symbolic`, tooltip and accessible label `Choose another image`) appears as a suffix,
    before the combo value, to pick a different file without leaving "Custom image".
  - Dismissed with no image stored for that console → the combo goes back to the previous choice.
  - Rejected (not a PNG, unreadable, over 16 MB, under 320×180) → toast `That file is not a PNG image`
    (or `That image is too small for a bezel` for the size case), combo back to the previous choice.

## States
- Default: every row `None`.
- Custom: subtitle + change button (image 1).
- Narrow window (< 400 px): rows wrap their titles; subtitle ellipsizes in the middle; the change button stays 34 px (image 2).
- Dark theme: libadwaita colors only, nothing hard-coded (image 2).
- Empty: not reachable (there are always 4:3 consoles), no empty state.

## In game (image 3)
- Bar shown (opaque): the bezel shrinks with the game, top-anchored, scale `1 − 60/720`, so the hole keeps hugging the image.
- Bar hidden, or the semi-transparent bar, or a driver with no shader pipeline (no margin pass): the bezel covers the full 16:9 box.
- The bar and its "show" button are always drawn on top of the bezel.

## Accessibility
- Every combo row has its console as title; the change button has an accessible label.
- Keyboard: Tab reaches each row and the change button; Enter opens the combo popover; Escape closes it.
- No new colors in the preferences UI; contrast is libadwaita's.

## Assets
- `src/openemux/data/bezels/simple.png` (1920×1080, transparent 4:3 hole 1440×1080 centered), generated by `scripts/build_bezels.py`, committed.
